**SentinelAI X – AI-Powered Cybersecurity Platform**

SentinelAI X is an AI-powered cybersecurity platform designed to enhance digital security through intelligent phishing detection, email threat analysis, and LLM security. It integrates PhishShield AI to identify suspicious emails, detect potential phishing attacks, and help protect users against evolving cyber threats.

Built with modern web technologies, SentinelAI X features a responsive security dashboard and **Supabase (PostgreSQL) cloud database integration** for reliable data storage and management. The platform also aims to integrate Gmail capabilities to analyze email messages and identify potential security threats.

**Key Features:**
- AI-powered phishing detection using PhishShield AI.
- Email threat analysis and suspicious content identification.
- LLM security and AI-based threat assessment.
- Supabase PostgreSQL cloud database integration.
- Responsive and interactive cybersecurity dashboard.
- Gmail integration for email security workflows.
- Modern web architecture with backend API integration.

**Goal:** To develop an intelligent cybersecurity ecosystem that leverages artificial intelligence and cloud technology to detect, analyze, and prevent digital threats.
